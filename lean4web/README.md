# Standalone Lean4Web proof

[BapatLalLean4Web.lean](BapatLalLean4Web.lean) contains the complete proof and
certificate, importing only Mathlib. Use Lean **v4.35.0-rc3**.

```bash
lake update
lake exe cache get
lake --wfail build BapatLalLean4Web
```

The file is generated by `../lean/scripts/make_lean4web.py`.
